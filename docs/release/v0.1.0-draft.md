This is a draft, not release notes for an existing tag or upload. Builds remain

## Added

Typed backend contracts and validated tools; a PydanticAI adapter; native session
snapshots with version guards; explicitly created in-memory sessions with same-session
serialization; linear async Workflow and conditional branching; structural logging
and OpenTelemetry; local CLI init/validate/run/trace; offline examples and packaging
checks for three distributions.

## Compatibility

Python 3.11 and 3.12 are tested. PydanticAI and pydantic-graph remain pinned to 2.48.0.
Package versions move together; public API is unchanged by this preparation phase.
Core/backend ship py.typed. Model construction belongs to the application.

## Known limitations

No durable workflow/DAG, persistent session store, multi-process ordering, commerce,
second backend, hosted service, interactive REPL or real-provider certification.
The CLI is local, reads stdin, has no provider schema and uploads no telemetry.
Framework spans exclude content; CLI formatting allowlists structural fields.
Applications own side effects, secrets, non-sensitive structural labels, native
history protection and any independently configured telemetry/exporters. No automatic
retry or rollback. Licensing and publication approval are unresolved; this is not production ready.
