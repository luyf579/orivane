# Publication gate

**DO NOT PUBLISH — LICENSE AND PUBLICATION GATES OPEN**

Status: OPEN. Repository remains PRIVATE. Packaging readiness does not authorize
public visibility, a tag, GitHub Release, PyPI or TestPyPI upload.

Before asking for a separate publication decision, review:

- Approved Orivane naming decision, package family, imports and executable;
  refresh registry availability before publication.
- Approved license and copyright/notice details.
- Security reporting/contact policy and enablement of private vulnerability reporting.
- README identity and any public authors/maintainers (not yet supplied).
- Full Git history secret audit, beyond Phase 1H's current-tree static scan.
- GitHub description/topics and final release notes.
- Verified ownership and access for the approved PyPI names.
- Metadata and clean installation after the rename/version change.

Do not read or configure publishing credentials in this phase. Current static scans
do not claim to establish a clean entire history. See [checklist](checklist.md).
