## Capabilities

Typed backend contracts; the PydanticAI backend; validated tools; versioned native
session state; an in-memory session runtime with one-process same-session ordering;
linear async workflows with conditional branches; structured logging/OpenTelemetry;
local CLI init, validate, run and trace; offline examples; verified wheel/sdist builds.

## Compatibility

Python 3.11/3.12. Three synchronized RC package versions and normal exact internal
dependencies. PydanticAI/pydantic-graph stay pinned to 2.48.0. Core/backend include
py.typed. No public class/function API is added by this phase. The pre-public
telemetry schema moves to Orivane with no compatibility aliases; see
[migration](rename-impact.md). CLI --version comes from installed metadata.

## Known limitations

One backend; in-memory sessions only; one-process serialization; linear workflows
only; no durable execution, persistent memory, commerce package, plugin ecosystem,
real-provider certification, or hosted service. Model construction and lifecycle,
side effects, retries, native-history protection and telemetry exporter configuration
belong to the application. CLI trace allowlists structural fields and never adds
provider content capture. No automatic rollback. This is early-stage pre-release
software, not production ready. Publication and Git identity review remain separate.
