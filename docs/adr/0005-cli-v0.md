# ADR-0005: Developer CLI v0

Package/import/command references reflect the approved Orivane rename. The original
architectural decision is unchanged; historical issues and Git history are preserved.

Status: Accepted

## Decision

Add a separate orivane-cli package with the approved `orivane`
console command and equivalent module entry point. Keep Core/backend public APIs
unchanged. Use Python 3.11 stdlib argparse, tomllib and importlib; no CLI framework,
YAML parser, templating engine or provider configuration layer is needed.

Use a strict schema-versioned TOML file containing only an application factory path.
A synchronous zero-argument factory returns an async runner that owns application
context and composition. Returning AgentBackend directly would force the CLI to
understand generic dependencies, sessions and workflows. Static validation never
imports application code, while run/trace intentionally execute trusted code.

Read the complete prompt from stdin instead of accepting --prompt, avoiding a default
command-line data channel. Print requested application output separately from local
trace metadata; error diagnostics contain safe categories rather than exception text.
Initialization uses fixed offline TestModel templates and refuses non-empty targets.

Trace owns an in-memory SDK provider in its one-shot CLI process, installed before
application import/factory construction. Refuse an already configured provider.
Flush/shutdown on exit; do not use private OTel reset APIs or Core private helpers.
Render only structural fields and a fixed attribute allowlist, without span events,
status descriptions, tool schemas or content. Do not install remote exporters.

## Consequences

The CLI directly depends on exact workspace Core/backend packages and the existing
OTel SDK. Existing package versions remain pinned; semantic-conventions is transitive.
There is no persistent session, provider schema, dotenv loading, REPL, YAML/JSON format,
hosted tracing integration or publishing command. Each process performs one invocation;
sys.path is restored, but Python's module cache is not reloaded. Trusted application
code retains responsibility for resources, side effects and its own output/exporters.
See [CLI documentation](../cli.md) for exit codes and privacy boundaries.
